# .impeccable/

Design-critique history for the console, written by the `impeccable` skill.

`critique/` holds one dated markdown snapshot per `/impeccable critique` run:
heuristic scores, findings, and severities. Committed on purpose — the point is
the trend across runs, and a score that only exists on one machine cannot be
compared against the next one.

`critique/ignore.md` (create if needed) lists findings not to re-raise: accepted
tradeoffs, deliberate deviations, and detector false positives. One per line.

Everything an agent needs to be a service.

  • Durable sessions. Turns are checkpointed. A restart resumes, it does not replay.
  • Identity built in. OIDC, service keys, tenants, roles, encrypted secrets.
  • Memory that lasts. Durable facts and semantic recall in your own Postgres.
  • One tool gateway. MCP servers and REST APIs, namespaced and authorized per call.
  • Real sandboxes. Code and browser execution in locked-down containers.
  • Operations included. Metrics, traces, evals, a CLI, and this console.
{{/* The differentiator, given a fold of its own. This is the reason someone chooses this over a managed agent cloud, so it gets the emphasis rather than being one bullet among eight. */}}

No managed cloud in the path. No egress. No vendor holding your transcripts.

Runs on a laptop, one production host, or Kubernetes. Air-gapped deployments are the point, not an afterthought.

Bring the agent you already have.

Go, Python, or any language that can speak HTTP. A conformance suite proves compatibility in CI, so "supported" is something you run, not something we claim.

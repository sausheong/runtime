What Runtime is

Runtime is the execution and operations layer between your users, your agent code, model providers, tools, and infrastructure. It turns an agent program into an operable service: durable sessions, process supervision, routing, authentication, and telemetry.

Its smallest useful deployment is one process and Postgres. The same binaries run on a laptop, a single production host, or Kubernetes, with no managed cloud agent service in the path.

Runtime does not

  • Provide a model. You bring the provider and the credentials.
  • Prescribe an agent framework. Native Go, Python SDKs, or any process that implements the HTTP/SSE contract.
  • Own your agent's prompt, domain tools, or product UI.

Capabilities

Durable runtime
Completed turns are checkpointed in Postgres, so a restarted agent resumes where it stopped rather than replaying the session. Sessions expose a real lifecycle, and SSE events are persisted before delivery and replayable from any sequence number. Operators cap turns, tokens, turn duration, and session duration.
Agent hosting
Local processes are supervised and restarted with capped backoff. Agents run as fixed replica pools or autoscale between bounds; a session stays pinned to the replica that can safely resume it, and scale-down drains before stopping. Remote agents attach over HTTP and can be registered or removed without a restart.
Identity and secrets
OIDC login for people, service keys for machines, and three tenant roles. Tenancy is enforced at the control-plane edge, so cross-tenant resources answer 404 rather than revealing themselves. Tenant credentials are stored as AES-256-GCM ciphertext, never returned by the API, and injected only at process start.
Memory
Tenant-scoped durable memory in Postgres with pgvector: explicit save and recall tools, semantic retrieval before a turn, and background extraction of durable facts from finished conversations. Recall is best-effort by design, so an embedding failure degrades retrieval instead of failing the user's turn.
Tool gateway
One MCP endpoint federating stdio servers, remote MCP servers, and REST APIs described by OpenAPI. Tools are namespaced per upstream, filtered by tenant, and authorized per call. Search mode keeps a large catalog callable without putting every schema in the model context.
Sandboxes
Per-session Python, shell, and browser execution in containers with a read-only root filesystem, resource limits, and no network by default. Browser egress is constrained by hostname policy below the application layer. State survives across calls within a session without exposing the agent host.
Evaluations
Golden sets scored by rule or judge, plus online sampling of live transcripts with failure classification. Runs are leased in Postgres and resume without rerunning completed cases. Credential-shaped fields are filtered before persistence, on a best-effort basis.
Observability
One Prometheus endpoint for the whole fleet on a separate management listener, a provisioned Grafana dashboard, OpenTelemetry traces over OTLP, and request IDs correlating logs to traces. Metric labels exclude session and user identifiers; message text never reaches a span.

Bring your own agent

Runtime integrates agents through a small HTTP and SSE contract. A reusable conformance suite runs that contract against a live agent, so compatibility is an executable CI gate rather than a claim.

Native Go Link agentruntime, supply a spec, provider, and tools. Full durable turn recovery.
Python Use the contract shim around the OpenAI Agents SDK, Claude Agent SDK, or another framework.
Any language Implement the contract directly and pass the same conformance suite.

Operating it

What it needs

  • Postgres, with pgvector when memory is enabled.
  • Docker with Compose v2 for the turnkey single-host stack.
  • No outbound internet: assets ship in the binary, and the bundled stack includes an embedder for air-gapped recall.

Know before you deploy

  • Durability is per completed turn. A side effect can repeat if the process dies mid-turn, so make such tools idempotent.
  • Sandbox containers use the Docker socket, which is root-equivalent on the host. The turnkey stack assumes a trusted node.
  • Terminate TLS at the edge. Open mode is for local development only.

Status

Runtime is pre-release software. The latest tagged release is v0.2.0, and the default branch carries unreleased changes.

The repository does not yet include a licence. The source is available to read, but no reuse or redistribution rights are granted until one is added, so Runtime should not be described as open source.

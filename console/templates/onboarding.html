OAuth2 client credentials

Client-credentials grant; the runtime fetches and refreshes access tokens. The client secret is write-only and never displayed.

On-behalf-of (OBO) token exchange

RFC 8693 token exchange; the runtime swaps the caller's JWT for a downstream token per human caller. OpenAPI upstreams only. The client secret is write-only and never displayed.

Rotate keyring

Re-seals every secret above with the current key. Cannot be undone, and any process holding an old sealed value must be restarted.
